# Cove MCP Server

## Introduction

The Cove Model Context Protocol (MCP) server allows AI systems and agents to interact with Cove's services programmatically. This enables AI applications, agentic systems, and other tools to help manage and submit rent reports, retrieve screening results, and perform other operations without requiring direct human interaction with the Cove API.

## What is MCP?

The Model Context Protocol (MCP) is a standard that connects AI applications and agentic systems with external tools and data sources. It allows AI systems to:

- Access real-time data from Cove's systems
- Perform actions on behalf of users (with proper authorization)
- Retrieve and analyze reports and screening results
- Submit and manage rent reporting data

For more information about the Model Context Protocol standard, visit the [official MCP documentation](https://modelcontextprotocol.io/docs).

## Server Configuration

### Sandbox Environment

To access the Cove MCP server in the sandbox environment, use the following configuration:

```json
{
  "cove": {
    "serverUrl": "https://sandbox-api.getcove.co/mcp",
    "headers": {
      "Authorization": "Bearer YOUR_API_KEY"
    }
  }
}
```

### Production Access

For production access to the Cove MCP server, please send an email to [team@cove.dev](mailto:team@cove.dev) with your request. The Cove team will provide you with the necessary credentials and configuration details.

## Available Functionality

The Cove MCP server currently provides the following functionality:

### Rent Reporting

- `GetReportData`: Retrieve detailed information about a rent report using its screening ID
- `MarkReport`: Update a report's status (ACCEPTED, REJECTED, or IN_REVIEW) with reasoning

### Coming Soon

We are continuously expanding our MCP capabilities. Future updates will include:

- Creation of custom fintech products (workflows)
- Advanced customization options for existing workflows

## Implementation Examples

### Retrieving Report Data

AI systems and agents can retrieve rent report data using the `GetReportData` tool by providing a screening ID. This tool returns comprehensive information about the rent report that can be analyzed and presented to users.

### Marking a Report

AI systems and agents can update report statuses using the `MarkReport` tool. This tool allows AI systems to set a report's status as ACCEPTED, REJECTED, or IN_REVIEW along with providing reasoning for the status change.

## Security and Permissions

When integrating with the Cove MCP server:

- Ensure proper authentication is maintained
- Store API keys securely and never expose them in client-side code
- Follow the principle of least privilege when requesting access
- Implement proper error handling for failed requests
